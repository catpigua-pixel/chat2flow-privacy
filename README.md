# Chat2Flow Privacy Policy

Public English-language privacy policy for the Chat2Flow Chrome extension.

Website: https://catpigua-pixel.github.io/chat2flow-privacy/

Contact: amy.huangjujun@gmail.com

## Updates

Edit `index.html` and commit the change to the `main` branch. GitHub Pages
automatically republishes the page. Keep the repository name and page path
unchanged to preserve the public URL.

This repository contains only the public policy website, not the extension
source code or any API keys.
