Chat2Flow Privacy Policy / 隐私政策

Last updated: August 24, 2026 / 最后更新：2026年8月24日

This policy describes how Chat2Flow (the “Extension”) handles information. The Extension is a bring-your-own-key Chrome extension that turns user instructions into diagrams.

本政策说明 Chat2Flow（以下简称“本插件”）如何处理信息。本插件是一款由用户自行提供 API Key、根据用户指令生成图表的 Chrome 插件。

1. Information handled / 处理的信息

The Extension handles course context, diagram instructions, chat messages, generated DiagramIR and draw.io XML, model and interface settings, a user-supplied OpenAI API Key, and—only when “Don't show again” is selected—a minimal record containing the current privacy-policy version.

本插件处理课程背景、图表指令、聊天消息、生成的 DiagramIR 与 draw.io XML、模型和界面设置、用户提供的 OpenAI API Key，以及仅在勾选“不再显示”时保存的当前隐私政策版本记录。

The Extension does not intentionally collect names, email addresses, IP addresses, browsing history, or webpage content. User-entered text may itself contain personal information. Do not enter passwords, identity documents, payment details, health information, or other sensitive data.

本插件不会主动收集姓名、电子邮箱、IP 地址、浏览历史或网页内容，但用户输入可能包含个人信息。请勿输入密码、身份证件、支付、健康或其他敏感信息。

2. Local storage and API Key security / 本地存储与 API Key 安全

Course context, chats, DiagramIR, diagram XML, and settings are stored locally using Chrome extension storage. The developer does not operate a separate server or database that receives this data.

课程背景、聊天、DiagramIR、图表 XML 和设置通过 Chrome 插件存储保存在本地。开发者未运营用于接收这些数据的独立服务器或数据库。

By default, the API Key is kept only in Chrome session storage. If the user explicitly saves it, PBKDF2-SHA-256 derives a key from the user's local password and AES-256-GCM encrypts the API Key locally. The password is never stored or transmitted and cannot be recovered.

API Key 默认仅保存在 Chrome 会话存储中。用户明确选择保存时，本插件使用 PBKDF2-SHA-256 从本地密码派生密钥，并以 AES-256-GCM 加密保存 API Key。密码不会被保存或传输，也无法恢复。

3. OpenAI / 发送给 OpenAI 的数据

Diagram requests send the current instruction, course context, recent chat history, the previous diagram structure when applicable, required system instructions, and the API Key directly to the OpenAI API over HTTPS. “Test connection” sends the API Key to OpenAI and requests the model list.

生成图表时，当前指令、课程背景、最近聊天记录、适用时的上一版图表结构、必要的系统指令和 API Key 会通过 HTTPS 直接发送给 OpenAI API。“测试连接”会向 OpenAI 发送 API Key 并请求模型列表。

OpenAI states that API data is not used to train or improve its models unless the account holder opts in. Default abuse-monitoring logs may include prompts, responses, and related metadata and may be retained for up to 30 days, subject to OpenAI's stated exceptions. Review the OpenAI API data controls and OpenAI Privacy Policy.

OpenAI 说明，除非账户持有人主动选择共享，否则 API 数据不会用于训练或改进其模型。默认滥用监控日志可能包含提示词、响应和相关元数据，并可能保留最多 30 天，但存在 OpenAI 公布的例外情况。请查阅上述 OpenAI 官方政策。

4. diagrams.net / 发送给 diagrams.net 的数据

Generated XML is sent by browser messaging to the embedded editor at embed.diagrams.net for display and editing. Only when the user explicitly opens the external application is XML included in the URL fragment opened at app.diagrams.net. No API Key is sent to diagrams.net. Review the JGraph privacy information.

生成的 XML 会通过浏览器消息发送给 embed.diagrams.net 的嵌入式编辑器。只有用户明确选择外部打开时，XML 才会包含在打开至 app.diagrams.net 的 URL 片段中。API Key 不会发送给 diagrams.net。

5. Use, sharing, and sale / 使用、共享与出售

Data is used only for the disclosed diagram-generation features and is shared only with OpenAI and diagrams.net as described above. The developer does not sell or rent user data, use it for advertising, transfer it to data brokers, or use it for creditworthiness or lending. The Extension has no developer-operated analytics or advertising trackers.

数据仅用于已披露的图表生成功能，并且仅在上述情形下与 OpenAI 和 diagrams.net 共享。开发者不会出售或出租用户数据，不会将其用于广告、数据经纪、信用评估或贷款。本插件不包含开发者运营的分析或广告追踪器。

The Extension's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements, and is limited to its disclosed single purpose.

本插件对信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求，并仅限于已披露的单一用途。

6. Retention, deletion, and choices / 保留、删除与选择

Local chats and diagrams remain until cleared or deleted, Chrome extension data is cleared, or the Extension is uninstalled. Settings and course context can be replaced. The API Key can be removed from Settings. OpenAI and diagrams.net retain data under their own policies and account settings.

本地聊天和图表会保留到被清空或删除、Chrome 插件数据被清除或插件被卸载为止。设置和课程背景可以替换，API Key 可以在设置中删除。OpenAI 和 diagrams.net 按各自政策和账户设置保留数据。

If “Don't show again” is unchecked, consent lasts only until the current page closes. If checked, only the current policy version is stored. A changed policy version requires consent again.

不勾选“不再显示”时，同意仅持续到当前页面关闭；勾选后仅保存当前政策版本。政策版本变化后需要重新同意。

7. Security / 安全措施

Extension-initiated network transmissions use HTTPS. Sensitive credentials are not sent to the extension developer. No storage or transmission method is completely secure; use an OpenAI API Key with appropriate project permissions and spending limits.

插件发起的网络传输使用 HTTPS，敏感凭据不会发送给插件开发者。任何方式都不能保证绝对安全，请为 OpenAI API Key 设置适当的项目权限和消费限额。

8. Changes / 政策变更

This policy may be updated when functionality, data practices, or legal obligations change. Material data-practice changes will be prominently disclosed before changed processing begins.

当功能、数据处理方式或法律义务变化时，本政策可能更新。重大数据处理变化会在新的处理开始前显著披露。
